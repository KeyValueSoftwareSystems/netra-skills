# TypeScript Custom Metrics

Custom metrics are **not currently supported** in the Netra TypeScript SDK. The Python SDK provides a `Meter` API for custom counters, histograms, gauges, and other signals, but an equivalent API is not yet available for TypeScript.

When support for custom metrics is added to the TypeScript SDK, the documentation will be updated accordingly. Until then, you can rely on the built‑in auto‑instrumentation for standard metrics.
